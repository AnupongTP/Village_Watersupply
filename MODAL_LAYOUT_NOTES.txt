Village Water Supply Dashboard — Data Completeness Modal Layout Patch
Date: 2026-08-19

Purpose
- Refine only the Data Completeness detail modal layout and its QA coverage.
- Intended to apply on top of the current cross-filter + deployment-path hotfix + user-location/non-sticky/back-to-top candidate.

Production behavior changed
1. Modal visible header is rendered inside the modal content flex layout, remains fully inside popup bounds, and includes a top-right × close control; SweetAlert's native title is retained only as the accessible dialog label.
2. Only the issue list scrolls; bottom ปิด action remains visible.
3. Desktop rows use compact columns: ระบบ / พื้นที่ | ประเด็น | การทำงาน.
4. Mobile rows keep actions beside record content instead of a separate full-width action row.
5. Mobile modal uses near-full viewport width without horizontal overflow.
6. Progressive reveal footer appears only when total > 20.
7. Show-more remains +20 per click and disappears at the end.
8. Detail Drawer return preserves expanded count and modal scroll context.
9. Map action behavior remains generic: only usable-coordinate system issue rows may expose it.
10. The former > 200 m³/h capacity-outlier heuristic is removed completely from Data Completeness issue calculation and modal sections; capacity completeness still checks whether the field is present.
